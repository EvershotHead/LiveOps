# 案例复盘：原神 7.0「无神怜爱的雪国」（B 站社区样本）

> T0 = 2026-08-12 · 相对窗口 T-7 ~ T+28 · 采集日 2026-09-11 · 匿名受限采样口径

## 1. 版本背景

- 7.0 为提瓦特第七国「至冬」开放版本：新地图至冬雪原、新角色奥黛塔（冰系单手剑）/阿罗夏（四星）、
  新元素反应「星烁」（星超导 / 星扩散体系的统称）、以及**版本最大争议点：第三人称射击玩法**（魔神任务强制换枪段落）。
- 前瞻直播披露 7.1「往冥府的安魂歌」将于 9 月中旬上线（本窗口末）。

## 4. 核心指标（分析 runs/full-genshin-7.0）

- 整体净支持率 **-0.409**（对比 6.8 的 -0.222，负面显著加深）。
- 主题占比 Top5：抽卡与商业化 22.6%（净 -0.71）/ 战斗与玩法 21.6%（净 -0.77）/ 剧情与世界观 20.6%（净 +0.50）/
  角色设计与美术 12.4%（净 +0.54）/ 平衡与强度 11.5%（净 -0.45）。
- 运营风险 Top3：战斗与玩法 0.642 / 剧情与世界观 0.527 / 官方沟通与社区生态 0.521。
- 正向机会 Top3：角色设计与美术 0.818 / 剧情与世界观 0.765 / 战斗与玩法 0.610。
- 结构解读：**"强叙事、弱玩法满意度"**——剧情与角色是明确正向锚点，
  射击玩法与抽卡体验是两个负面聚集地，且前者贡献了最高的风险分。

## 5. 运营要点（引用 metric_id 与 evidence_id，最终以报告页为准）

- **射击玩法是本版本最大负面聚集地**：问题报告集中在"移动端不当人""强制换枪生理性不适（3D 眩晕）"
  "视角偏左不适应""近战/滑铲缺失"。该主题的运营问题优先级待填。
- **抽取与商业化**：歪卡叙事高频（迪卢克/七七/琴/刻晴），"痛失14原石"类副本遗憾成为版本梗；
  胡桃等老角色复刻诉求持续。
- **正向信号**：新版本引导工具（宝箱罗盘、探索笔记）获具体称赞；奥黛塔机制归纳类攻略互动健康；
  树人支线/蓝藻剧情的叙事讨论深度高于均值。
- **社区生态新问题**：大世界中玩家恶意摆放干扰装置（弹跳装置害雪球破裂等）引发大量抱怨，
  "举报通道缺失"与"屏蔽功能"是明确的用户诉求——这是 7.0 样本中独有的新运营问题。

## 6. 局限性

1. 匿名受限采样，样本量低于方案目标，代表性有限。
2. 全量标注为开发 Agent 强模型层（非人工金标），标签质量待人工复核层校准。
3. 争议度与组合分数是可配置排序规则，非客观事实；权重敏感性见仪表盘。
4. 不代表全体玩家；仅 B 站讨论样本。
