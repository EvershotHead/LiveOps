## 5. 运营要点（引用 metric_id 与 evidence_id，最终以报告页为准）

- **性能是高声量双面话题**：性能与缺陷主题占比约 15.7%、净支持率 -0.58——闪退/卡顿/掉帧抱怨仍占主导；
  但官方优化推送后出现了密度可观的具体称赞（"学院能跑满帧""功耗降 1.5 瓦"），
  是运营响应可见生效的正例，方向性改善明确但尚未扭转情绪。
- **性别角色争议是最大社区冲突面**：男角色供给/待遇讨论贯穿抽卡、剧情、社区行为三个层面，
  情绪强度高且对线频繁；"清宵强度/待遇"与"景燃剧情量"是争议的具象载体。
- **玩法机制争论**：清宵（震谐）与莫宁绑定度、穗穗操作稳定性、轮椅配队 vs 操作上限，
  是强度讨论的三大持久话题。
- **福利口径不满**：大月卡性价比、版本免费抽数（"这版本星声少的可怜"）是奖励争议的集中点。

## 6. 局限性

1. 匿名受限采样 + 发酵期窗口截断（T+22），样本量与时间覆盖均低于方案目标。
2. 全量标注为开发 Agent 强模型层，标签质量待人工复核层校准。
3. 联动内容（明日方舟画师梗等）在样本中占比高，跨游戏语境的弃权判别已如实计入弃权率。
4. 不代表全体玩家；仅 B 站讨论样本。
