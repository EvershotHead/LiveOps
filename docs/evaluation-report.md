# 模型评测报告（真实数字 · 2026-08-16）

## 0. 口径声明（先读）

本报告严格区分三层证据，**不虚报任何数字**：

1. **管道正确性（回放校验）**：ScriptedLLM 回放 800 条种子标注走完整分析管道。
   回放一致性 **100.0%**（两游戏各 400/400 字段级一致）。
   这证明「导入→规范化→相关性→聚类→标注→路由→聚合→报告→验证」链路与聚合公式正确，
   **不构成模型质量证据**（输入输出同源）。
2. **向量基线（无密钥模式的真实评测）**：bge-m3 嵌入 + 主题质心分类 vs 种子金标，
   按视频分组切分（训练 70% / 测试 30%，同视频不跨集）。这是当前模式下的真实模型数字。
3. **LLM 结构化标注质量**：**未测量**。用户配置 LLM 密钥后运行
   `uv run liveops run --fixture synthetic_100 --real` 或对冻结样本全量标注即可获得；
   届时本报告与演示站将用真实数字更新。

## 3. 校准与弃权（种子层）

- ECE（10 桶，相关性维度）：原神 0.555 / 鸣潮 0.596 —— 种子标注置信度偏保守（大量 0.2-0.45 低置信弃权样本），校准一般，人工复核优先队列应聚焦高置信错误与低置信摇摆样本。
- 反讽维度弃权率（种子层）：原神 31.8%（127/400 无法判断）、鸣潮 34.8%——与标签手册"梗语境不足允许弃权"的设计一致。
