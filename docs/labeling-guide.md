# 标签手册 v1.0

> 适用范围：LiveOps Community Intelligence 全部标注工作（模型结构化标注、强模型种子标注、人工标注与复核）。
> 修改本手册必须递增版本号，并同步修改 `backend/liveops/schema/enums.py` 的 `LABEL_SET_VERSION`。
> 通用底线：**网络梗、反串、引用他人观点、语境不足的内容，允许且鼓励选"无法判断/不明确"，禁止强行二分。**

## 0. 标注总则

1. 只依据评论文本及其楼中楼可见语境判断，不脑补视频画面内容。
2. 一条评论可命中多个主题（多标签），但立场/情绪/反讽是单选。
3. 对"转述别人观点"（如"有人说这版本抠门，我倒觉得还行"），立场按评论者本人的最终态度标，转述部分作为语境。
4. 玩梗内容若无法确定真实态度 → 立场"不明确"、反讽"无法判断"是正确答案，不是标注失败。
5. 与游戏版本运营无关的内容（纯广告、抽奖、其他游戏、无意义字符）→ `relevant=false`。
6. 拿不准时降低 confidence 并保持标签保守（不明确/无法判断），交由复核路由处理。

## 1. 相关性（relevant）

| 值 | 定义 | 示例 |
|---|---|---|
| true | 与该游戏该版本的可运营议题相关（玩法/剧情/角色/运营动作/社区事件等） | "6.8的深渊怎么感觉更肝了" |
| false | 明确无关：广告、抽奖楼、其他游戏、纯表情刷屏、无意义字符 | "恭喜发财大吉大利今晚吃鸡" |
| null(弃权) | 语境不足无法判断 | 单独一个"？" |

## 3. 立场（单选）

| 值 | 定义 | 示例 |
|---|---|---|
| 支持 | 明确正面态度 | "这版本真香" |
| 反对 | 明确负面态度 | "越来越敷衍了" |
| 中立 | 有观点但无褒贬倾向（陈述事实/中性提问） | "本次更新加了两个活动" |
| 混合 | 同一评论内明确同时含正负两面 | "地图好看但剧情拉了" |
| 不明确 | 无法确定态度（玩梗、反串、语境不足） | "就这？" |

## 4. 情绪（单选）与强度（0-3）

情绪：喜悦 / 期待 / 惊讶 / 失望 / 愤怒 / 焦虑 / 调侃玩梗 / 无明显情绪。
选**主导情绪**；强度：0=无情绪陈述，1=轻微，2=明显，3=激烈（感叹号连用、人身攻击倾向、强烈安利）。

## 5. 反讽（单选）

| 值 | 定义 | 判断线索 |
|---|---|---|
| 无 | 非反讽 | |
| 可能 | 疑似但不确定 | 语气与内容矛盾、阴阳怪气但缺实锤 |
| 明显 | 明确正话反说/阴阳怪气 | "太感谢了，又歪了"配负面语境 |
| 无法判断 | 梗过深/引用他人/语境不足 | 二创黑话、"典""急了"单独出现 |

## 6. 表达意图（单选）

称赞 / 体验陈述 / 问题报告 / 改进建议 / 提问 / 玩梗 / 冲突回应（回复中与他人争论）/ 传闻讨论（爆料、内鬼消息）。

## 7. 问题性质（单选，仅问题类内容）

内容不足 / 设计分歧 / 数值争议 / 技术故障 / 奖励争议 / 沟通问题 / 社区冲突 / 其他。非问题类内容可不填。

## 8. 置信度与证据

- confidence ∈ [0,1]：标注者对自己上述判断的把握，不是评论的"情绪浓度"。
- evidence_span：从原文中截取最能支撑判断的 ≤40 字片段（人工标注同样要求填写）。
- 弃权：任何维度无法判断时可弃权（relevant=null），必须写 abstain_reason。

## 9. 金标准两层策略（2026-08-16 确认）

1. **第一层·强模型种子**（`annotator_type=strong_model_seed`）：由开发 Agent（强模型）对每游戏 400 条生成结构化种子标注，用于验证流水线与标签体系、支撑初期评测。
2. **第二层·人工标注**（`annotator_type=human`）：用户通过标注工作台逐条复核种子标注，可接受/修改，全部修改记录进 HumanReview（字段级 diff + 原因）。
3. 评测报告**分开报告**两层口径；模型种子标注不得冒充人工金标准。人工复核完成后，人工层即金标准层。
