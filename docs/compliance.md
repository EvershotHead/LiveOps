# 数据合规说明（v1）

## 1. 基本立场

本项目是个人研究与作品展示用途的**公开社区内容分析**，遵循"只碰公开、最小采集、可审计、可删除"原则。

## 2. 只做什么

- 仅处理**未登录状态公开可见**的 B 站视频元数据与评论区内容。
- 采集限速（评论接口 ≥2.5s/请求）、单会话请求上限、失败退避、断点续采、全程日志。
- 文件导入模式只处理用户自有/自行整理的数据，产品核心能力不依赖采集。

## 3. 绝不做什么

- ❌ 不登录采集登录后专属内容，不绕过登录墙。
- ❌ 不绕过验证码、风控、频控；出现风控信号（412/-352/验证码）立即硬停，不重试、不换 UA、不换 IP。
- ❌ 不采集用户主页、私信、粉丝列表、UID 关联个人资料；不建立用户画像。
- ❌ 不做实时监控、不做舆情操纵、不向第三方出售数据。
- ❌ 不把合成数据冒充真实玩家数据（合成夹具显式 `synthetic=true`，演示站不展示为玩家洞察）。

## 4. 匿名化（不可逆）

- 采集时**立即**将 uid 替换为 `HMAC-SHA256(study_salt, uid)[:16]`；原始 uid 不落盘（含 journal）。
- 盐保存在本地 `secrets/`（gitignore），公开数据包不含盐 → 无法反推。
- 删除字段：用户名、头像、UID、主页链接、会员信息。
- 文本内 `@用户名` 提及在公开导出时掩码为 `@***`。
- 公开导出前运行泄漏扫描（正则 + 字段白名单），断言通过才允许导出（见测试 test_anonymize.py）。

## 5. 数据保留与删除

- `data/raw/`（未匿名原始数据）：仅本地保存，gitignore，项目交付前可整目录删除而不影响产品运行。
- `data/anon/` 与 `demo/public-data/`：匿名化后的分析数据，可公开。
- 任何人可通过 issue 请求删除特定视频来源的全部数据；由于匿名化不可逆，无需删除个体用户记录（不存在可识别个体）。

## 6. 平台条款与法律

- B 站用户生成内容著作权归原作者；本项目仅做聚合统计分析与短片段引用（≤80 字），附来源链接，符合研究性引用惯例。
- 公开演示站展示"所采样的 B 站讨论"口径，不缓存平台内容副本到公开仓库（仅匿名化文本片段）。
- 本项目不构成对任何平台的官方背书；商标与游戏名称归各自权利人。

## 7. LLM 使用边界

- 社区文本作为**不可信数据**传入模型：显式数据边界标签 + 注入防护声明 + 严格 JSON 输出（见 llm/guard.py 与测试）。
- 不把评论文本发送到除配置的 LLM 端点以外的任何服务；密钥仅存本地 `.env`。
- 模型不计算任何最终指标（Python 计算）；模型内部思维过程不保存不展示。
